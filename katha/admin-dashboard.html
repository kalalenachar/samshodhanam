📤 Import Stories

📝 File Instruction

JSON format: An array of story objects. Each object must have title and content_html. The cover_image_url is required only for published stories. Optional fields: summary, category, cover_image_url (for drafts), author, reading_time, status, and published_at.

Excel format: A spreadsheet with columns: title, summary, content_html, category, cover_image_url (required only if status is 'published'), author, reading_time, status, published_at. Download the sample for the exact format.

ZIP format: An archive containing text files named like XX StoryTitle.txt and cover images named like XX.png (matching the leading number of the text file). Missing covers import as drafts.
