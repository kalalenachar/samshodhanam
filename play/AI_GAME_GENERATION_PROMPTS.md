# Sanskrit Games - AI Prompt Guide 🎮✨

This guide contains copy-pasteable system prompts to feed into large language models (like Google Gemini, ChatGPT, or Claude) to generate new game sets. The output generated by the AI can be directly pasted into a `.json` file and uploaded using the **Bulk Upload** button in the dashboard.

---

## 1. Synonym Match (पर्याय-मेलनम्)

### Copy-Paste Prompt:

```text
You are an expert Sanskrit language AI model.
Please generate a synonym-match game set.

Topic: [ENTER TOPIC HERE, e.g., "Animals", "Nature", "Gods", "Rivers"]

Your output must be formatted as a JSON array containing one set object.
The set object must match this JSON structure:
[
  {
    "title": "Set Title in Sanskrit (e.g., प्राणी-पर्यायाः)",
    "pairs": [
      { "word": "Sanskrit Word in Devanagari", "synonym": "Its synonym in Devanagari" }
    ]
  }
]

Requirements:
- Provide exactly 6 to 10 synonym pairs.
- Make sure the words are correct Sanskrit, commonly used, and spelled accurately in Devanagari.
- Output ONLY the valid JSON array. Do not wrap it in markdown code blocks like ```json ... ```. Do not add any conversational text or comments.
```

## 2. Word Builder (शब्द-रचना)

### Copy-Paste Prompt:

```text
You are an expert Sanskrit language AI model.
Please generate a word builder game set.

Topic: [ENTER TOPIC HERE, e.g., "Devas", "Fruits", "Basic Verbs", "Colors"]

Your output must be formatted as a JSON array containing one set object.
The set object must match this JSON structure:
[
  {
    "title": "Set Title in Sanskrit (e.g., देव-नामानि)",
    "syllables": ["Syllable 1", "Syllable 2", "Syllable 3", ...],
    "target_words": ["Target Word 1", "Target Word 2", ...]
  }
]

Requirements:
- `syllables` must be a pool of individual Devanagari syllables/characters (e.g., "रा", "म", "ः", "ग", "ज").
- `target_words` must be a list of 4 to 8 Sanskrit words in Devanagari that can be built by combining syllables from the pool.
- Ensure that EVERY syllable required to form each target word is present in the `syllables` pool.
- Output ONLY the valid JSON array. Do not wrap it in markdown code blocks like ```json ... ```. Do not add any conversational text or comments.
```

## 3. Word Search (शब्दान्वेषणम्)

### Copy-Paste Prompt:

```text
You are an expert Sanskrit language AI model.
Please generate a word search grid game set.

Topic: [ENTER TOPIC HERE, e.g., "Fruits", "Colors", "Rivers", "Trees"]
Grid Size: [ENTER GRID SIZE HERE: 4 or 5 or 6]

Your output must be formatted as a JSON array containing one set object.
The set object must match this JSON structure:
[
  {
    "title": "Set Title in Sanskrit (e.g., फल-नामानि)",
    "grid_size": 4, 5, or 6,
    "target_words": ["Word 1", "Word 2", "Word 3", ...]
  }
]

Requirements:
- Target words must be valid Sanskrit words in Devanagari.
- Ensure the number of syllables/letters in each target word does not exceed the chosen `grid_size`.
- Provide exactly 4 to 8 target words.
- Output ONLY the valid JSON array. Do not wrap it in markdown code blocks like ```json ... ```. Do not add any conversational text or comments.
```

## How to Import the Output:

1. **Copy** the prompt for the desired game type.
2. **Paste** it into your AI assistant (Gemini/ChatGPT/Claude). Replace the `[ENTER TOPIC HERE]` placeholder with your desired theme (e.g., "Vegetables").
3. **Copy the JSON output** returned by the AI.
4. Open a text editor (like Notepad), **paste** the JSON, and save it as a file with a `.json` extension (e.g., `animals.json`).
5. Open the **Games Admin Dashboard**, navigate to the relevant game tab, click **Bulk Upload**, select the JSON file, and click **Confirm Import**.
