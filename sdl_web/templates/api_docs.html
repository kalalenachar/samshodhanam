📚 SDL API v1.0 Documentation

Welcome to the Sanskrit Digital Library API. This API allows you to programmatically access books, search OCR text, and retrieve page contents.

🔒 Authentication

All requests must include your API Key in the HTTP header:

X-API-Key: your_api_key_here

🚀 Endpoints

GET /api/v1/books

Returns a list of all books in the library.

GET /api/v1/search

Perform an advanced text search across all books.

ParameterTypeDescription
qStringText to search for (Sanskrit or Roman)
tagsStringFilter by book tags
normalizeBooltrue to ignore vowel marks/accents (default: true)
logicStringand or or for multiple terms (default: or)
modeStringcontains, exact, starts_with, ends_with
limitIntMax results per book (default: 0, unlimited)
GET /api/v1/book/{book_id}/page/{page_num}

Retrieve the full text content of a specific page.

POST /api/v1/suggest

Submit a general suggestion, correction, or feedback to the Superadmin.

ParameterTypeDescription
contentStringThe text of your suggestion (required)

Example: {"content": "Add more books on Ayurveda..."}

POST /api/v1/feedback

Submit a "Thumbs Up" or "Thumbs Down" rating and comments for a specific book/page.

ParameterTypeDescription
book_idStringThe exact folder name of the book (required)
statusStringEither "up" or "down" (required)
pageNumberThe page number (optional)
commentStringAdditional notes (optional)

Example: {"book_id": "Rigveda", "status": "down", "page": 5, "comment": "OCR error in line 2"}

📦 Response Format

All responses are returned in JSON format.

{
  "success": true,
  "count": 1,
  "results": [
    {
      "book": "Rigveda_Mandala_1",
      "page": 45,
      "text": "... context around the match ...",
      "archive_url": "https://archive.org/details/rigveda1"
    }
  ],
  "time_sec": 0.12
}
