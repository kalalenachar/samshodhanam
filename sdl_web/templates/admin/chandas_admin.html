ℹ️ About This App

Chandas is a Sanskrit prosody (meter/छन्दस्) analyzer that scans verses, classifies each syllable as Laghu (˘) or Guru (¯), identifies the meter (छन्दस्), and provides fuzzy correction suggestions for metrical inconsistencies.

Key Features: Syllable-level Laghu-Guru analysis, verse-level meter detection (Anushtubh, Vasantatilaka, Shardulavikridita, etc.), fuzzy edit-distance correction engine, and sample verse presets for quick testing.

📖 Supported Meters

The Chandas engine recognizes all classical Sanskrit meters from the Pingala Chhandas-Shastra. Meter detection works on individual lines (pāda) as well as complete verses (shloka).

Anushtubh (अनुष्टुप्) Indravajra (इन्द्रवज्रा) Upendravajra (उपेन्द्रवज्रा) Upajati (उपजाति) Vasantatilaka (वसन्ततिलका) Mandakranta (मन्दाक्रान्ता) Shardulavikridita (शार्दूलविक्रीडितम्) Sragdhara (स्रग्धरा) Malini (मालिनी) Shikharini (शिखरिणी) Rathoddhata (रथोद्धता) Arya (आर्या)

+ many more samavritta and ardhasamavritta meters supported by the underlying chanda engine.

⚙️ Engine Details

The Chandas analyzer runs server-side using the chanda Python library with verse_mode=True and fuzzy=True enabled. This mode preserves verse-level context for collective meter detection.
